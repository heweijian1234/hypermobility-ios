## 一、这版是什么

从 0.1.0（2026-10 上架的纯记录工具）到 1.1，中间隔了 8 个测试包（build 34–43）。
1.1 是**第一次改版 + 第一次收费**，两件事压在同一个版本里。

### 界面改版（0.4.0 → 0.5.2）

| 改动 | 解决的问题 |
|---|---|
| 纸感设计系统（paper/ink/accent + 严重度四档热力色） | 旧版是绿黄橙红交通灯，黄底白字对比度只有 1.5:1，看不清 |
| 首页三个悬浮圆按钮 → 底部单一主按钮 | `overlay` 不参与 List 布局，旧版会压住最后一行 |
| 快速记录改成半屏确认卡 | 旧 `quickLog()` 的 bodyPart 取上一条、severity 写死 2，用户看不到也改不了——**静默写错数据** |
| 详细表单 8 段 → 首屏可完成 | 旧版要滚 10 行选择器 |
| 报告页：大号数字 + 页内条形图 + 30 日热度条 | 统计信息埋在 PDF 里，页面上看不到 |
| 照片对比：单列堆叠 → THEN/NOW 并排 + 可全屏缩放 | 旧版看不出对比 |
| 首页近 7 天窗口 + 展开入口 | 记录一多列表无限长 |
| 周柱状高度改平方根映射 | 旧公式一天 3 条就顶格，7 根柱子看着一样高 |

### 本地化（0.5.0）

**之前从来没做过。** 历史是两次硬编码整体替换（`2ae0965` 全中文 → `a40ebca` 全英文），没有 `.lproj`、没有 `NSLocalizedString`。

1.1 补上：`en.lproj` / `zh-Hans.lproj` 各 168 条，跟随系统语言。
关键坑：SwiftUI 的 `Text("字面量")` 会自动查表，但**字符串变量、数组标签、`String(format:)` 模板不会**——所以部位/严重度/时长/处置/诱因/Beighton 九项全走 `L()` 辅助函数。

### 商业化（1.1 新增）

免费 → 付费的边界：

| | 内容 |
|---|---|
| **免费** | 无限记录、照片、Beighton 自评、本周概览、点柱看当天、编辑 |
| **Pro $4.99 买断** | 导出医生报告（PDF / CSV / 纯文本）、照片并排对比、全部记录页 |

配套改动：
- 首页列表瘦身——每行只留「部位 + 日期时间 + 严重度」，疼痛持续/处置/诱因/备注全部收进详情。**理由：原来太方便，不会有人付费**
- 未补细节的条目标记 `DRAFT` 胶囊
- 报告页/照片对比页未解锁时显示 PRO 标识 + 入口

## 三、关键决策与理由

| 决策 | 理由 |
|---|---|
| **$4.99 而非报告里写的 $19.99** | 健哥 11-25 拍板：当前功能单一，$19.99 站不住；后续有新功能再升 |
| **导出/对比/全部记录 三块收费** | 记录本身免费（降低开始门槛、保证数据积累），「把数据变成能给医生看的东西」收费。这个边界好解释、不恶心人 |
| **不做开屏动画** | HIG 不鼓励延迟进入内容的启动动画；场景是「刚脱臼，打开记一笔」，任何等待都是负担。改为把 LaunchScreen 背景设成纸色，消掉白闪 |
| **锁 Light 模式** | 深色模式未适配，不半吊子上线。`INFOPLIST_KEY_UIUserInterfaceStyle` 对 XcodeGen 显式 plist 无效，必须写进 `info.properties` |
| **App 名不本地化** | 图标下仍显示 `HyperLog`，商店名用「HyperLog 关节记录」——纯中文名会和桌面割裂 |
| **欧盟 DSA 暂不声明** | 没有办公地址，声明交易商 = 公开家庭住址。代价对个人开发者太重。欧盟 27 国不可分发，不影响美/日/其他区 |
| **删掉测试数据功能** | 上架前移除，`TestDataView.swift` 已删，中英各 11 条文案已清 |
